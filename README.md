# Scratch Game: Star Collector 🌟

A fun arcade-style game built as part of Harvard's CS50 course[cite: 1]. The objective is simple: collect as many stars as possible while dodging incoming balls!

## 🎮 How to Play
1. Download or clone the repository.
2. Open the `.sb3` file using the [Scratch Offline Editor](https://scratch.mit.edu/download) or import it into the [Scratch Website](https://scratch.mit.edu/).
3. Press the green flag to start playing. Use your controls to maneuver and survive!

## 🛠️ Built With
* **Scratch 3.0** - Visual block-based programming language
